# 채점 기준과 연습용 앵커

평가는 화면에 보이는 행동을 기준으로 한다. 렌더링 성공, JSON 스키마 통과, 계획과 입력의 일치만으로 행동 성공을 판정하지 않는다.

## 요구별 판정

- `pass`: 요구를 확인할 수 있고 충족한다.
- `fail`: 확인 가능한 반례가 있다. 예: 오른손 요청에 왼손 사용, 앞쪽 요청에 뒤쪽에서 수행, 일어서기 전에 종료.
- `uncertain`: 가림/구도/화질 때문에 결정할 수 없다. 잘 되었을 것이라고 추정하지 않는다.

조건을 모르는 두 평가자가 각 요구를 독립적으로 판정한다. 모든 요구를 `pass`로 합의해야 성공이다. 두 평가자가 서로 다른 요구를 실패로 표시한 경우도 불일치이며 같은 총점이라는 이유로 합의 처리하지 않는다. 제3 평가자가 요구별 근거를 남겨 판정한다.

## 행동 앵커

| 항목 | 통과 예 | 실패 예 |
|---|---|---|
| 좌우 | 캐릭터 본인의 오른손이 움직임 | 화면 오른쪽을 신체 오른쪽으로 오해 |
| 앞뒤 | 손이 몸통 전방에 위치한 채 동작 | 어깨가 뒤집혀 손이 등 뒤로 이동 |
| 왕복 1회 | 손이 한 방향으로 이동한 뒤 같은 시작 쪽으로 돌아옴 | 한 방향 이동만 하고 멈춤 |
| 순서 | 첫 손을 내린 이후 반대 손 동작 시작 | 두 손이 동시에 움직여 순서를 위반 |
| 유지 1초 | 25fps라면 약 25프레임, 24fps라면 약 24프레임 동안 목표 상태 유지 | 자세에 잠깐 도달했다가 바로 해제 |
| 초기 자세 | 앉은 이미지에서 앉은 상태로 동작 시작 | 첫 프레임 직후 서 있는 자세로 순간 재설정 |
| 종료 | 요청된 복귀/기립/팔 내림이 클립 안에 보임 | 핵심 자세에 도달했지만 복귀 전에 영상 종료 |

왕복은 손의 주된 이동 경로를 따라 세며, 손목/손가락의 작은 떨림을 별도의 왕복으로 세지 않는다. 횟수가 가림으로 보이지 않으면 uncertain이다. 시간 요구는 정확한 한 프레임을 강요하지 않고 ±0.2초의 허용 오차를 사용한다. 몸 앞/어깨 높이 등은 캐릭터 몸 기준이며 카메라 축 기준이 아니다.

## 부 결과(별도 기록)

자연스러움: 1=큰 비정상 굽힘/튀는 동작이 지속됨, 3=행동은 알아볼 수 있으나 눈에 띄는 어색함, 5=눈에 띄는 부자연스러운 관절/전환이 없음. 2/4는 사이 수준. 외형 보존, 시작 이미지 연속성, 시간적 아티팩트는 각각 판단하며 합산하지 않는다. 이 텍스트 앵커만으로 평가자 보정이 완료된 것은 아니다. calibration 영상이 실제 생성되면 독립 연습·논의 후 본 평가를 시작해야 한다.

현재 실제 채점 예제 영상/사람 평가 결과는 없다. 거짓 정답 영상을 만들어 이미 보정된 척하지 않는다.
