이 문서는 벤치마크 v0.2의 실행 결과와, 그 이전 v0.1 마네킹 입력으로 수행한 예비 실험 결과를 정리한 것이다. 본 평가(test-001)의 최종 영상 36개는 평가자 1인(연구자)이 판정하였다. 사례가 12건이므로 신뢰구간이 넓고, 아래 수치는 조건 간 우열의 검정이 아니다.

**공통 실행 조건:**

## v0.2 실행

v0.2 입력은 AI로 생성한 가상 인물의 캐릭터 그림체 이미지 8장(개발 D1–D4, 평가 T1–T4)과 일상적인 요청 20개(개발 8, 평가 12)이다. 실사풍 이미지는 Seedance가 실존 인물의 모습일 수 있다는 콘텐츠 정책으로 거부하여(HTTP 422 `content_policy_violation`) 같은 인물·자세·시점·구도의 캐릭터 그림체로 바꾸었다. 레퍼런스 마네킹은 LLM이 이미지에서 판단한 체형(키, 연령대, 체격)으로 만들고, 판단한 시점과 화면 구도로 렌더링한다. 검증기는 v6이다.

### 평가 실행 test-001 (본 평가)

- **동결**: 실행 전에 코드·프롬프트(계획·검증·영상 프롬프트 포함)의 SHA-256 지문, 플래너(sonnet), 480p, 비용 상한 42달러를 `run.json`에 기록하였다.
- **레퍼런스 게이트**: 12건 모두 통과하였다. T06(박수)과 T11(점프)은 1회 수정 후 통과하였고, 나머지 10건은 최초 레퍼런스로 통과하였다. 이 10건은 조건 B와 C가 같은 레퍼런스를 쓰므로, 두 조건의 차이는 생성 변동이다.
- **최종 영상**: 12문항 × 3조건(A 직접 I2V, B LLM 레퍼런스 R2V, C 검증 레퍼런스 R2V) = 36개를 모두 생성하였다. 추정 비용은 25.09달러, 영상 1개의 생성 지연은 132–355초이다.
- **체형·시점 판단**: 같은 이미지에서도 요청마다 판단이 달랐다(예: 아동 T1을 세 요청 중 두 번은 청소년으로 판단). T11의 첫 프레임 방향이 입력과 반대였던 것처럼, T4의 시점 방향 판단이 정의와 어긋났을 가능성이 있다.
- **사람 평가**: 평가자 1인이 조건을 숨긴 익명 패키지로 36개 영상을 모두 판정하였다. 판단 불가는 0점으로 센다. 원본 판정은 `runs/test-001/ledger.json`의 `review`, 집계는 `summary.json`에 있다(저장소 미포함).

- 평가자 메모: 레퍼런스 조건의 여러 영상에서 동작 전후의 전환(B T01·T07, C T02·T05·T07·T11)과 템포(B T02·T06)가 부자연스러움. B T11은 동작 사이에 멈췄다 다시 움직이고 지시하지 않은 동작이 붙음. B T05는 손 흔드는 방향이 이상함. C T08은 동작 직전에 한 번 멈춤. A T09는 지시하지 않은 행동까지 이어서 함. A T12는 동작 전이 조금 부자연스러움.
- 해석(이 평가 세트에 한정): 직접 I2V에서도 R1 실패가 없어 연구 동기로 삼은 실패가 재현되지 않았다. 레퍼런스 방식은 행동 수행률을 높이지 않았고 자연스러움은 낮았다. 이는 레퍼런스의 키프레임 타이밍과 멈춤이 최종 영상에 옮겨진 결과로 볼 수 있다. B와 C는 10건에서 같은 레퍼런스를 썼으므로 두 조건의 차이에는 생성 변동이 포함된다.
- 조건 B와 C의 차이: B는 최초 레퍼런스를 검사 없이 R2V에 넣고, C는 검증기를 통과한 레퍼런스만 쓴다(실패 시 1회 수정·재검토, 그래도 실패하면 차단). test-001에서는 10건이 최초 레퍼런스로 게이트를 통과하여 B와 C가 같은 레퍼런스 영상을 썼다(레퍼런스 해시로 확인). 레퍼런스가 달랐던 것은 T06(박수 쳐: B 통과·3, C 통과·5)과 T11(점프해: B 통과·5, C 통과·4)뿐이며, 두 건 모두 C가 수정본을 썼다.
- 같은 레퍼런스 10건의 차이는 생성 변동이다. T12(팔짱 껴)는 B 판단 불가·1, C 통과·5로 R1까지 갈렸고(주 지표의 B·C 차이는 이 한 건), T01(2/1)·T02(1/2)·T05(1/2)·T09(3/4)는 자연스러움만 달랐다. T03(팔짱 껴)은 두 조건 모두 판단 불가·1이다.
- 결론: 차이가 생길 수 있는 사례가 2건뿐이어서 이번 평가에서는 검증 단계의 효과가 사실상 측정되지 않았다. 또 생성 변동이 커서 반복 생성 없이 1회 생성으로 조건을 비교하는 데에는 한계가 있다. 다음 평가에는 반복 생성과 검증 실패 사례를 포함해야 한다.
- 실패 유형(평가자 메모와 프레임 확인): 단계를 나누어도 실패가 사라지지 않고 유형이 바뀌었다.
  - 레퍼런스 오류: 판단 불가 3건은 모두 팔짱 끼기. T03 레퍼런스는 두 팔뚝이 가슴 앞이 아니라 화면 아래 가장자리에서 겹쳐 일부가 잘렸고, T12 레퍼런스(측면 웅크리기)는 팔뚝이 무릎과 겹쳐 팔짱 모양이 드러나지 않았다. 검증기 v6는 둘 다 통과시켰다. T12는 같은 레퍼런스의 C가 통과(5점)했으므로 B의 판단 불가를 레퍼런스만의 문제로 볼 수는 없다.
  - 부자연스러운 전환: 자연스러움 A 4.17, B 2.75, C 3.33. 평가자 메모는 동작 전후 전환, 템포, 중간 멈춤에 집중.
  - 요청 이상의 동작(직접 I2V): T09는 뒤돈 뒤 화면 밖으로 걸어 나감(판단 불가, 메모 "시키지 않은 행동까지 이어서 함"), T11은 점프 뒤 다시 쪼그려 앉음, T03은 팔짱 전에 한 팔을 옆으로 크게 뻗음. 나머지 A 영상에서는 뚜렷한 추가 행동을 확인하지 못함.
- 레퍼런스에 대한 사람 판정과 검증기 대조는 미실시.

### 비용

영상 생성 추정 비용은 dev-009 5.53달러, test-001 25.09달러이다. 그 밖에 개발 실행 dev-007에서 0.74달러가 들었고, 이 실행에서 다운로드 오류로 같은 요청이 다시 제출되어 중복 과금 1건(약 0.6달러)이 생겼다. 정확한 청구액은 fal 대시보드를 따른다. 플래너와 검증기는 Claude 구독으로 실행하여 별도 API 비용이 없다.

### 레퍼런스 검증

### 레퍼런스 사람 평가 (4차 실행)

4차 실행의 레퍼런스 8건을 평가자 1인(연구자)이 익명 패키지로 평가하였다. 평가자는 입력 이미지, 요청 문장, 레퍼런스 영상만 보았으며 검증기 판정은 보지 않았다.

| 항목 | 결과 |
|---|---|
| 모든 요구 충족 | 8건 중 7건 |
| 판단 불가 포함 | 1건 (D08: "몸통을 똑바로", "세운 뒤") |
| 미충족 판정 | 0건 |
| 자연스러움 (1–5) | 평균 3.9, 최저 2 (D03) |
| 검증기와 요구 단위 일치 | 37건 중 35건 (94.6%) |

불일치 2건은 모두 D08에서 검증기는 충족, 사람은 판단 불가로 판정한 경우이다. 검증기가 모든 요구를 충족으로 판정하여 Cohen's κ는 0으로 계산되며 의미 있는 지표가 아니다. 사람이 미충족으로 판정한 레퍼런스가 없으므로, 검증기가 잘못된 레퍼런스를 놓치는 비율은 이 평가로 측정할 수 없다.
