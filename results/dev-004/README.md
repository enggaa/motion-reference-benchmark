# dev-004: 레퍼런스 파이프라인 일관 실행 (development 8건, 2026-10-29)

**무엇인가:** `python -m motionbench pipeline --run runs/dev-004 --model sonnet`을 한 번 실행한 결과입니다.
- **단계**: 자세 호출 → 실루엣 맞춤 → 계획 → 렌더·등록 → 조건 C 게이트(검증기 v3).
- **실행 방식**: 모든 그룹을 같은 코드로 1회씩 돌렸고, 재시도나 선별은 하지 않았습니다.
- **비용**: Claude 호출 30회, 출력 약 11만 토큰, 모델 대기 시간 약 11분입니다. 모두 구독 사용량입니다.
- **없는 것**: 최종 영상(Seedance)과 사람 평가는 없습니다.

## 계획의 약점: 반복 횟수

LLM 계획은 왕복 횟수를 자주 틀립니다(1.5/2, 2/1, 0/1). 검토자의 지적을 받은 수정도 D05에서는 같은 오류를 되풀이했습니다. 개선 후보는 횟수를 LLM의 키프레임 나열에 맡기지 않는 것입니다. LLM이 한 주기의 극점 자세와 `repetitions`만 내고, 코드가 주기를 반복해 키프레임을 펼치게 하면 됩니다. 사전 키프레임을 변형·조합한다는 연구 의도와도 맞습니다.
