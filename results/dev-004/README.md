## 정정: 왕복 수 산식은 믿을 수 없다 (같은 날 추가)

위 표의 "왕복" 값은 손을 든 상태의 전환점 수로 계산한 (n−1)/2입니다. v3 검증기도 같은 규칙을 받았습니다. 그런데 손의 좌우 위치를 시계열로 다시 보면, 이 산식은 손이 어디서 출발했는지를 무시합니다.

- **D01** (cm, + = 바깥, 든 시점 기준): 5 → 18 → 4 → 18 → 4. 안쪽에서 출발한 밖→안→밖→안이므로 RUBRIC 정의로 **2왕복, 요청대로**입니다. v3의 blocked는 산식 때문에 생긴 **거짓 판정일 가능성이 큽니다**.
- **D05 오른손**: 30에서 출발해 37로 조금 나갔다가, 10까지 크게 안으로 들어왔다가, 29로 돌아갑니다. 출발 위치 기준으로 보면 **1왕복**으로 읽힙니다.

그래서 처음 썼던 "LLM 계획이 반복 횟수를 자주 틀린다"는 결론은 **철회합니다.** 계획의 키프레임 설명은 D01, D05 모두 요청과 같은 왕복 수를 적고 있습니다. D06 최초(밖으로 한 번만 나감)는 시계열로 다시 확인해야 합니다.

조치: v4 검증기는 손의 좌우 위치 시계열(약 0.1초 간격)과 RUBRIC의 왕복 정의를 받습니다. dev-004 렌더를 ledger를 건드리지 않고 v4로 재검토한 결과는 `rereview_v4.json`과 아래에 정리합니다.
