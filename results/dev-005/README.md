# dev-005: 계획 규칙 6 + 검증기 v4 (development 8건, 2026-10-30 새벽)

**무엇인가:** dev-004 이후 두 가지를 바꾸고 `pipeline`을 한 번 실행한 결과입니다. 최종 영상과 사람 평가는 없습니다.

- **계획 규칙 6**: 반복은 두 극점 사이를 오가는 깨끗한 흔들기로 만들고, 마지막 흔들기 뒤에 가운데로 돌아가는 동작을 넣지 않습니다.
- **검증기 v4**: 든 손의 좌우 위치 시계열을 보고, RUBRIC의 왕복 정의로 셉니다.
- **비용**: Claude 호출 24회, 출력 약 7만 토큰, 모델 대기 약 7분입니다. 모두 구독 사용량입니다.

계획 프롬프트가 바뀌어서 계획 단계는 dev-001~004와 직접 비교하지 않습니다.

## 사람 평가 준비

레퍼런스 익명 평가 패키지를 만들었습니다(`package-review --kind reference`, 8항목). 평가자는 `rate.html`을 브라우저로 열어 판정하고 파일을 저장합니다. 평가자 2명의 파일이 모이면 아래를 실행합니다.

```bash
python -m motionbench import-ratings --run runs/dev-005 --mapping runs/dev-005/private/reference_mapping.json --rater ratings_A.json --rater ratings_B.json
python -m motionbench agreement --run runs/dev-005
```

그러면 검증기 v4의 판정이 사람과 얼마나 맞는지 나옵니다.
